# 我在哪（Android App）

一款为老年人设计的**定位 App**：打开即显示当前详细地址与经纬度，超大字体、高对比度、零学习成本。

- 当前版本：**v0.6.6**（versionCode 6）
- 包名：`com.wozai.app`
- 兼容：Android 7.0 ~ 14（minSdk 24 / targetSdk 34）

---

## 功能特点

- **打开即定位**：进入 App 自动申请权限并定位，按设定间隔刷新；也可手动点「重新定位」。
- **大字老人界面**：24–40sp 超大字体、米黄色高对比度背景，关键按钮大而醒目。
- **语音朗读**：点地址朗读详细地址，点经纬度逐位朗读（不会把小数读成"几十万"），点喇叭按钮重读。
- **一键打开高德**：长按地址直接调起高德地图 App 主图自行定位（未安装则打开网页版兜底）。
- **分享位置**：一键复制地址+地图链接并跳转微信；也可用短信把位置发给家人（默认数据卡发送）。
- **网络信息卡片**：显示运营商、制式（仅 4G/5G）、小区标识 CID，并在括号内给出「基站ID_小区标识」。
- **三级地址解析**：高德 → 腾讯 → 系统 Geocoder 依次回退，任一家未配置或失败自动降级。
- **常用位置**：可把常去地点存起来、编辑、快速查看。
- **数据备份**：支持把配置与常用位置导出为 JSON 文件、从文件恢复。
- **日志导出**：长按标题第一个字「我」进入设置 → 导出日志到「下载」目录（txt），便于排查问题。
- **纯系统定位**：使用 `LocationManager`（GPS + 基站/WiFi），不依赖 Google 服务，适配国产手机。

> 本 App **只在打开时定位**，不做后台持续定位。

| 操作 | 效果 |
|---|---|
| 点按地址 | 朗读详细地址 |

| 点喇叭按钮 | 重读当前地址 |

| 长按标题「我」 | 进入设置菜单 |
| 长按弹窗标题「设置」 | 进入地图 Key 与定位参数设置 |

- **JDK 17**

## 配置

### 地图 Key（App 内填写）
高德、腾讯的 Web 服务 Key **不在源码中写死**，而是在 App 内填写：长按标题「我」→ 设置 → 地图 Key 与定位设置。源码 `res/values/map_keys.xml` 里两个字段保持为空。

- 这两个 Key 仅用于把坐标解析成详细地址（Web 服务接口），**不需要**绑定包名/签名。
- Key 单独存放在 `app_keys` 私有存储中，被系统自动备份规则排除（不上云）；但 App 内的「数据备份」功能会把 Key 写进导出的 JSON 文件，用于换机恢复——该文件请只保存在本地。

### 定位参数（设置项）
| 项目 | 默认值 | 范围 / 说明 |
|---|---|---|
| 定位间隔 | 15 秒 | 5~600 秒；留空或 0 = 手动（仅点刷新/回前台时定位一次） |
| 最小距离 | 5 米 | 1~1000 米 |
| 定位超时 | 自动 | 留空 = 建议值（间隔+5 秒，手动模式 15 秒）；可填 5~180 秒 |

## 权限说明

| 权限 | 用途 |
|---|---|
| 精确定位 / 大致定位 | 获取当前位置（核心功能） |
| 联网 / 查看网络状态 | 调用高德/腾讯逆地理编码接口 |
| 读取手机状态 | 识别双卡运营商/基站，取当前上网卡发短信 |
| 发送短信 | 把位置信息直接发给家人 |
| 写外部存储（仅 Android 9 及以下） | 导出日志/备份到「下载」目录 |

App 首次打开会弹出定位权限询问，点「允许」即可。若误点「拒绝」，到「设置 → 应用 → 我在哪 → 权限 → 位置信息」开启。

---

## 关于基站信息

App 读取的是运营商基站编号（小区标识 CID），**这些数字本身不含经纬度**。要换算成坐标需调用基站定位数据库接口（需申请 Key），本 App 未内置该能力。

读取基站信息需要定位权限；部分机型在 Android 10+ 上如返回空，请确认系统「位置信息」开关已打开。

---

## 隐私说明

- 只在 App 打开时定位，**无后台持续定位**。
- 定位与地址解析均在本机发生，位置不上传自建服务器。
- 地址解析会请求高德/腾讯的公开 Web 服务接口（若已配置 Key）。
- 日志中的 Key、手机号、姓名会做脱敏处理。
- 地图 Key 不参与系统自动备份（不上云）；但 App 内的「数据备份」导出的 JSON 文件会包含 Key，该文件仅存本地、请勿外传。
